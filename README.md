# Beginner C Practice Project

## Description
This project is a beginner-level C programming practice project that combines multiple concepts in one program.

It includes:
- personal information output
- a number guessing game
- an item inventory system using structs
- a simple calculation function

## Features
- Displays basic personal information
- Includes a random number guessing game
- Stores item details using structs
- Calculates the sum of quantity and size for each item

## Technologies Used
- C Programming Language
- Standard C Libraries:
  - `stdio.h`
  - `string.h`
  - `stdlib.h`
  - `time.h`

## Concepts Practiced
- functions
- structs
- strings
- random numbers
- user input
- formatted output
- basic calculations

## How to Run
1. Open the project in Code::Blocks or any C compiler
2. Compile the program
3. Run the executable
4. Follow the prompts
